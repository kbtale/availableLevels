# Available Levels Tables

This repository contains a set of static HTML tables designed for displaying course schedules.

## Purpose
These tables were specifically created to be embedded as components within other websites. They provide a structured layout for:
- Adult schedules (Martes/Jueves, Miércoles/Viernes, Sabatino, Intensivo)
- Youth schedules (Jóvenes)
- Children's schedules (Niños)

## Structure
- `/`: The main version of the tables with enhanced tab layouts.
- `/Levels/`: A secondary or legacy version with alternate styling.

## Usage
The files are standalone HTML/CSS/JS and were meant to be integrated into any web page that required a responsive and tabbed schedule display. It was used by specific local orgs but, of course, this is old, outdated, and no longer maintained.
